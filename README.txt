# NeXvora Premium Fashion — Free E-commerce Website

1. `index.html`, `style.css`, `script.js` একই folder-এ রাখুন।
2. `script.js`-এ `phone="8801XXXXXXXXX"` এর জায়গায় আপনার WhatsApp নম্বর দিন।

5. Free hosting-এর জন্য GitHub Pages-এর মতো static hosting ব্যবহার করা যায়।
